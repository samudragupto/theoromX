# Winners Photos Directory

Place the winner photos in this directory with the following exact filenames to display them on the TheoremX 2026 website (both desktop and mobile versions):

- `winner_showcase.jpg`  ->  Best Research Showcase Winner
- `winner_solution.jpg`  ->  Best Innovative Solution Winner
- `winner_demo.jpg`      ->  Best Technical Demo Winner
- `winner_prototype.jpg` ->  Best Prototype Winner
- `winner_tech.jpg`      ->  Best Emerging Tech Winner
- `winner_choice.jpg`    ->  People's Choice Award Winner

### Image Specifications:
- **Format:** JPEG (.jpg or .jpeg)
- **Aspect Ratio:** 1:1 square crop is recommended (e.g., 400x400 pixels) for the best circle display.
- **Size:** Keep file size small (under 200KB per photo) for fast page loading.

*Note: The website features an automatic fallback. If a photo is missing, a beautiful vector icon in the department's purple theme color will be shown instead of a broken image.*
